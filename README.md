# Noor — نور

تطبيق **Noor** رفيق متكامل وآمن وخاص للمسلم، مبني بـ React Native (Expo SDK 57).

## المميزات

- 💾 مواقيت الصلاة بدقة (GPS / اختيار مدينة / إحداثيات يدوية) بطريقة حساب Egyptian والحنفي/الشافعي
- 🔔 تنبيهات صلاة قبل/بعد موعد الصلاة، وأذكار الصباح والمساء والنوم، وتقرير سورة الكهف يوم الجمعة
- 🕌 صوت الأذان عند وقت الصلاة مع إنذار كامل الشاشة
- 📖 المصحف الشريف بعدة روايات (حفص، ورش، قالون، الدوري، السوسي، البزي، قنبل، شعبة) — الحفص متاح بدون إنترنت
- 🧭 القبلة بالبوصلة مع المسافة إلى الكعبة
- 📿 المسبحة (Tasbeeh) وجلسات الأذكار
- 💰 حاسبة الزكاة والآلة الحاسبة
- 🗓 التاريخ الهجري، الثلث الأخير من الليل ومنتصف الليل الشرعي
- 🔐 مركز أمان: قفل التطبيق برمز PIN (PBKDF2 + تأخير ضد التخمين)، تشفير البيانات AES-256، اتصال HTTPS فقط
- 🎨 5 ثيمات (أخضر، أزرق، ذهبي، داكن، فاتح) و5 لغات (العربية، الإنجليزية، الفرنسية، الأردية، التركية)

## التشغيل

```bash
npm install
npx expo start
```

## بناء APK للأندرويد

```bash
npx expo prebuild -p android
cd android && ./gradlew assembleRelease
```

التحميل المباشر: شاهد [Releases](https://github.com/AlfaDev0/agon-noor-mobile/releases)
